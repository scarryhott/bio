# Existing derived closure topologies for the biological AGI runtime

Status date: 2026-08-05

This document records the closure topologies already derived across the Black Mirror, ARC/AGI, Closure–Chaitin, Topos–Turing, MainStreet/Tagtokn, and biological coevolution projects. It does not introduce a new fixed catalogue of admissible charts. Closure remains the originless generator/operator; the structures below are recurring return-disclosed readings, operational motifs, and carrier organizations already used in the project.

## 1. Intrinsic closure relation

The prior relation is:

```text
L(C) ← C → G(C)
```

Local and global are projections of `C`, not primitive domains. A topology becomes admissible only through the same return-unified episode it attempts to resolve:

```text
(C_t, E_t, A_legal,t) ↔_C (A_t, E_t+1, R_t, V_t, C_t+1)
```

`V_t` is endogenous. Missing return remains `OPEN`; witnessed contradiction is `FALSE_COLLAPSE`; refusal blocks write-back.

## 2. OPEN Potential Gate

The Potential Gate is the unresolved topology-forming carrier before one chart is selected as authoritative.

```text
G_t = (B_t, H_t, Sigma_t, Omega_t, rho_t, Gamma_t, Pi_t, A_t)
```

- `B_t`: current perspectival ball/local carrier
- `H_t`: possible global hair/continuation
- `Sigma_t`: maintained semantic or biological relations
- `Omega_t`: unresolved openings
- `rho_t`: authority, provenance, mandate, consent
- `Gamma_t`: ordered interaction/intervention history
- `Pi_t`: observer-relative return-side partition
- `A_t`: axiometric shadows such as scores, entropy, confidence, fitness, digests, and PASS counts

An independent return discloses a return-anchored quotient topology and recovery contract. Unresolved branches remain OPEN or become child Potential Gates.

## 3. Local ball / global hair topology

The local ball is the current observer-relative folded basis. The global hair is the nonlocal continuation through environment, history, other modalities, and future consequence.

```text
local ball
→ global exposure
→ transformed return
→ local/global repartition
```

Neither side is permanently fixed. The observer's perspectival ball determines the initial side label; return curvature may exchange sides and return exactly under involution.

Biological reading:

- ball: nucleotide, motif, molecule, cell, assay, organism, participant, or learned genomic chart
- hair: DNA-reader/writer dynamics, tissue state, environment, intervention history, phenotype, population/evolution, or later measured consequence

## 4. 0↔∞ predual closure

`0` is the global originless/predual basis before local polarization, not local zero collapse. `∞` is the complementary open continuation. Their fold is a self-dual closure locus:

```text
0 ↔ ∞
localization ↔ global continuation
fold ↔ unfold
```

The `0∞` reading supports unitary continuation, rotation/extension, and local/global exchange without identifying the two poles as identical coordinates.

## 5. Rotation / extension topology

Rotation and extension are paired presentations of one closure trajectory. Existing derivations use `tan(pi/2)` folds and ball-top inversion to represent a passage where an apparent endpoint becomes a continuation basis.

Operationally:

```text
presentation
→ rotation / extension
→ transformed contact
→ returned presentation
```

In biology this can represent conformational change, template advance, or environment-dependent reversal without reducing the operation to a scalar displacement.

## 6. Fold / glue topology

Distinct carriers can be glued into one returned relation without being identified as the same object.

```text
DNA ≠ RNA ≠ protein ≠ phenotype
```

Yet they may close through one recoverable cross-modal relation. Fold/glue therefore preserves non-identical recovery and rejects flat-embedding identity as sufficient verification.

## 7. Self-limit topology

Self-limit is the return trajectory through which a relation becomes identifiable by its completed continuation, not an ordinary numerical limit.

```text
basis
→ transformed continuation
→ recovered basis relation
```

A return is admissible when the maintained relation survives the trajectory. If return is not a basis of curvature, it is a collapse.

## 8. Curl/homology and divergence/homotopy cycle equality

The project distinguishes a basis cycle and closure cycle:

```text
basis cycle: derivative / curl / homology side
closure cycle: integral / divergence / homotopy side
```

Closure is derived when the cycles and encode↔evaluate topoi align. These are not preselected evaluators; their equality is itself resolved through return.

## 9. Relation / releta / phase topology

A relation is represented as complex `z`; releta is its modulus `||z||`; phase is the unitary part.

```text
z = unitary phase × ||z||
```

The modulus is a shadow of the maintained relation, not the whole identity. Phase carries relative orientation and return direction.

Partition curvature distinguishes complementary return sides and permits exact side exchange:


## 16. Topos–Turing reciprocal admissibility

The project uses a mutual-admissibility framework:

```text

A(C(R)) ≈ R
C(A(U)) ≈ U
```

This is called a Topos–Turing mutual-admissibility framework, not a literal topos theorem. Biological state changes admissible computation, and computation changes the next observable biological state.
